# 🦊 Kitsune Assistant — KITSUNE // LIVING FLAME HUD

Голосовой ассистент-компаньон для рабочего стола с киберпанк-HUD в стиле
девятихвостой лисицы-кицунэ. Работает **полностью локально**: распознавание речи
идёт офлайн через Vosk, анимация и интерфейс — на `customtkinter`.

Скажи «**Лисичка**» — и она запустит Steam, откроет YouTube, свернёт окна
режимом невидимки, заблокирует клавиатуру от кота, подержит экран от засыпания
и сделает скриншот. Всё управляется голосом и настраивается через HUD.

> Внешний вид: тёмный HUD-интерфейс с анимированным «реактором» из неонового
> пламени, который реагирует на уровень голоса, панелью телеметрии и чатом.
> Аватар лисички лежит в `resources/fox_avatar.png` и легко заменяется.

## 📋 Требования

- **Windows 10 / 11** — обязательно. Ассистент использует `powercfg`, SAPI5,
  `ctypes.windll`, `winreg`, блокировку клавиатуры и буфер обмена.
- **Python 3.9+** (проект проверен на 3.12). При установке включи галочку
  «Add python.exe to PATH».
- **Микрофон** — для голосового ввода.
- **Интернет** — только для нейроголоса `edge-tts`. Без сети ассистент сам
  переключится на системный голос SAPI5 и продолжит работать.

## 🚀 Быстрый старт

Всё делает один скрипт: создаёт виртуальную среду `.venv`, ставит зависимости и
запускает ассистента.

**Git Bash / MSYS2 (bash):**

```bash
./run.sh              # поднять окружение и запустить в фоне (без окна консоли)
./run.sh --foreground # запустить с консолью: видно логи Vosk и ошибки
```

**cmd.exe / PowerShell (нативный Windows):**

```bat
run.bat               :: поднять окружение и запустить в фоне
run.bat --foreground  :: запустить с консолью
```

Флаги обоих скриптов:

| Флаг | Действие |
| --- | --- |
| (без флага) | Собрать окружение и запустить ассистента в фоне. |
| `--setup` | Только создать `.venv` и установить зависимости. |
| `--foreground` | Запустить с консолью — удобно для отладки. |
| `--reinstall` | Переустановить зависимости с нуля. |
| `--help` | Справка. |

> Зависимости переустанавливаются автоматически, когда меняется
> `requirements.txt` (скрипт сравнивает файл с копией `.venv/.requirements.lock`).

## 🗣️ Как пользоваться

1. После запуска в системном трее появляются **две иконки**: основная
   (Kitsune Core) и переключатель энергопрофиля (солнце/луна).
2. В окне HUD нажми «**👂 СЛУШАТЬ ЭФИР**» — микрофон включится автоматически.
   Ассистент дремлет и ждёт активационную фразу.
3. Окликни: «**Лисичка, включи музыку**». Если сказать только «Лисичка» —
   она отзовётся и подождёт команду.
4. Дальше в течение `wake_timeout` секунд (по умолчанию 7) можно говорить
   команды без повторного оклика.
5. Двойной клик по центральной зоне (реактору) переключает полный режим и
   мини-норку. Закрытие окна прячет ассистента в трей.

Полезные фразы из коробки: `что ты умеешь`, `вылезай`, `в норку`, `прячься`,
`прячем хвост`, `время охоты`, `яндекс музыка`, `ютуб`, `телеграм`, `резка`,
`кошачий замок`, `лисий след`, `охранять нору`.

## 📜 Свиток повадок: свои команды

Команды хранятся в `commands/<язык>.command` в формате JSON:

```json
{
  "commands": {
    "время охоты": {
      "synonyms": ["запусти стим", "хочу играть"],
      "steps": [
        { "action": "set_volume", "value": "15" },
        { "action": "run_cmd", "value": "\"C:\\Program Files (x86)\\Steam\\steam.exe\"" },
        { "action": "speak", "value": "Готово, идём на охоту!" }
      ]
    }
  },
  "responses": { "unknown": ["Не поняла, повтори?"] },
  "chitchat": {
    "praise": {
      "triggers": ["умница", "ты супер"],
      "responses": ["Мурр-уруру! Спасибо!"]
    }
  }
}
```

Шаги выполняются **строго по порядку**. В поле `value` можно перечислить
несколько вариантов фразы через `|` — тогда ассистент выберет случайную.

Проще всего редактировать это через вкладку «**СВИТОК ПОВАДОК**» в HUD:
слева список команд с поиском, справа конструктор шагов и синонимов.

### Доступные действия (`action`)

| `action` | `value` | Что делает |
| --- | --- | --- |
| `speak` | текст | Озвучивает фразу (`вариант1 \| вариант2` — случайный выбор). |
| `get_power_mode` | — | Докладывает текущий энергопрофиль. |
| `show_full_window` / `show_mini_window` / `hide_to_tray` | — | Полный режим / мини-норка / трей. |
| `fullscreen` | — | Нажимает `F11`. |
| `list_commands` | — | Выводит список навыков. |
| `lock_keyboard` / `unlock_keyboard` | — | Кото-замок: блокирует/разблокирует клавиатуру. |
| `toggle_sleep_mode` | — | Переключает профиль сна (5 мин ↔ никогда). |
| `sleep_never` / `sleep_5min` | — | Явно включить «не засыпать» / эко-сон. |
| `open_url` | URL | Открывает сайт в браузере по умолчанию. |
| `run_cmd` | команда | Запускает программу через shell (поддерживает `%localappdata%` и т.п.). |
| `hotkey` | `win+d` | Нажимает сочетание клавиш. |
| `type_text` | текст | Печатает текст в активное окно через буфер обмена. |
| `screenshot` | — | Сохраняет снимок экрана на рабочий стол. |
| `set_volume` | `0…100` | Выставляет громкость. |
| `volume_up` / `volume_down` / `volume_mute` | шагов | Громче / тише / без звука. |
| `media_play_pause` / `media_next` / `media_prev` | — | Управление плеером. |
| `pause` | секунды | Задержка между шагами. |
| `lock_pc` / `sleep_pc` | — | Блокировка экрана / перевод ПК в сон. |

## ⚡ Энергопрофили (важно!)

Ассистент **реально меняет системные таймауты питания** через `powercfg`:

| Профиль | Сон | Экран | Признак |
| --- | --- | --- | --- |
| Дрёма в норке | 5 мин | 5 мин | маркера нет |
| Чуткий дозор | никогда | 30 мин | создан файл `~\.sleep_never_marker` |

Переключается командой `toggle_sleep_mode`, через трей или правый клик по иконке
энергопрофиля. Вернуть стандартные значения можно в «Электропитании» Windows.
На ноутбуке профиль «Чуткий дозор» заметно расходует батарею.

## 🧠 Модель распознавания речи

В папке `model/` лежит компактная русская модель Vosk (подходит для слабых
машин). Ядро само находит модель: ищет внутри `model/` каталог, содержащий
`conf/`. Если модель не найдена, ассистент запустится, но напишет в чат
«Модель Vosk не найдена» и не будет слушать.

Другие модели (в том числе английские) можно скачать на
[alphacephei.com/vosk/models](https://alphacephei.com/vosk/models) и распаковать
в `model/`.

## 🎯 Точность распознавания речи

Точность складывается из трёх независимых слоёв — и улучшать их нужно по-разному.

### 1. Акустика (модель Vosk)

В `model/` лежит **маленькая** русская модель `vosk-model-small-ru-0.22`
(WER ~23 % на аудиокнигах и ~32 % на YouTube). Точность ограничена самой моделью,
и никакие настройки это не обходят. Варианты:

| Путь | Что даёт | Цена |
| --- | --- | --- |
| Текущая small-модель | Быстро, ~300 МБ RAM, поддержка grammar-режима | Базовая точность |
| `vosk-model-ru-0.42` (1.8 ГБ) | WER ~4.5 % на аудиокнигах — 2–3× точнее | Больше RAM/CPU, **grammar-режим недоступен** |

Важно: у больших моделей Vosk словарь **нельзя** менять в рантайме
(`SetGrammar` работает только с small-моделями). То есть grammar-режим и большая
модель — взаимоисключающие пути.

### 2. Декодирование: grammar-режим (включён по умолчанию)

Вместо распознавания «чего угодно» декодер ограничивается словарём команд —
253 фразы из `commands/<язык>.command` плюс оклики и болталки. Замер на
синтезированной речи:

| Фраза | grammar | open |
| --- | --- | --- |
| «лисичка включи музыку» | ✅ 0.07 с | ✅ 0.56 с |
| «лисичка время охоты» | ✅ 0.08 с | ✅ 0.58 с |
| «сегодня хорошая погода» | ❌ «сил хорошая работа» | ✅ 0.54 с |

Отсюда два вывода: на командах grammar-режим **в 7 раз быстрее** и устойчивее к
шумам (декодер достраивает фразу до ближайшей известной), но **речь вне словаря
он подгоняет под ближайшую фразу словаря**. Поэтому:

- не отключай `require_wake_word` — оклик остаётся главным фильтром;
- выключи `asr_grammar`, если часто говоришь свободным текстом;
- добавляй нужные фразы в `asr_grammar_extra`, а не полагайся на догадки декодера.

Полезно знать: латиница в русской модели отсутствует как класс. Слова `fox`,
`kitsune`, `youtube`, `telegram`, `hdrezka` в неё не входят — Vosk их молча
отбрасывал и до включения grammar-режима, то есть такие синонимы не работали
никогда. Пиши команды по-русски (`ютуб`, `телеграм`) — сейчас грамматика такие
фразы отфильтровывает автоматически.

### 3. Сопоставление текста

Фразы нормализуются (нижний регистр, `ё`→`е`, без пунктуации) до сравнения, счёт
считается как максимум из `ratio` и `partial_ratio`. Пороги вынесены в
`asr_cmd_threshold` / `asr_chitchat_threshold` / `asr_chitchat_strong`, так что
их можно подкручивать без правки кода.

### 4. Распознавание на видеокарте (faster-whisper)

Если в системе есть NVIDIA, ассистент по умолчанию (`asr_engine: "auto"`)
переводит распознавание на **faster-whisper** через CUDA. Это другая нейросеть
(`large-v3-turbo`, ~1.6 ГБ) — она качается один раз в кэш HuggingFace и заметно
точнее маленькой Vosk. Замер на RTX 3070 (`int8_float16`):

| Фраза | whisper (GPU) | Vosk small |
| --- | --- | --- |
| «лисичка включи музыку» | ✅ 0.21 с | ✅ 0.56 с |
| «лисичка время охоты» | ✅ 0.22 с | ✅ 0.58 с |
| «сегодня хорошая погода» | ✅ **верно** | ❌ в grammar-режиме искажает |

Ключевое отличие: whisper **не подгоняет** речь под словарь команд, поэтому
фразы вне словаря распознаются корректно, в отличие от grammar-режима Vosk.

**Автоматический выбор движка.** `asr_engine: "auto"` идёт по цепочке и на первом
отказе остаётся на Vosk (CPU) — на слабых машинах поведение не меняется:

1. модуль `faster-whisper` установлен;
2. CTranslate2 видит CUDA-устройство;
3. VRAM карты не меньше `whisper_min_vram_mb` (по умолчанию 3000 МБ);
4. модель успешно загрузилась — иначе откат на Vosk прямо во время работы.

Что выбралось, видно в логе строкой `[ASR] ...`, и в чате при старте прослушивания.

**Установка.** `run.sh` / `run.bat` сами ставят GPU-зависимости из
`requirements-gpu.txt`, если найдут `nvidia-smi`. Вручную:

```bash
.venv/Scripts/python -m pip install -r requirements-gpu.txt
```

Ускоритель не обязателен: без карты или без этих пакетов всё работает на Vosk.
Первый запуск с GPU скачает модель (~1.6 ГБ) — это разовая задержка.

**Настройки whisper** (в `config.json`):

| Ключ | Назначение | По умолчанию |
| --- | --- | --- |
| `asr_engine` | `auto` / `vosk` / `whisper`. | `auto` |
| `whisper_model` | Модель: `large-v3-turbo`, `medium`, `small`… | `large-v3-turbo` |
| `whisper_compute_type` | Пусто = подобрать под карту (`int8_float16` и т.п.). | `""` |
| `whisper_min_vram_mb` | Порог VRAM: ниже — остаёмся на Vosk. | `3000` |
| `vad_silence_ms` | Тишина после речи, завершающая фразу. | `700` |
| `vad_energy_factor` | Во сколько раз речь громче фона. | `2.2` |
| `vad_max_utterance_s` | Максимальная длина одной фразы. | `12` |

`asr_grammar` при работе на whisper не применяется: ограничивать словарь незачем.

### Как диагностировать

Включи в настройках **«Показывать в чате сырое распознавание»** (`asr_debug`).
На каждую фразу в чат придёт строка вида:

```
🔎 ASR: ASR[G] "лисичка включит музыку" | оклик=лисичка | команда=лисья песня 86 | болталка=40
```

- `W` — whisper на видеокарте, `G` — grammar-режим Vosk, `O` — Vosk без словаря.
  Если стоит `O` при включённом `asr_grammar`, значит словарь не собрался
  (см. лог `[Vosk] Распознавание: ...`);
- слова искажены, счёт низкий → проблема в акустике: микрофон, шум, маленькая модель;
- слова верные, но счёт ниже порога → подкрути порог или добавь синоним.

Это разделяет «модель не расслышала» и «фраза не сопоставилась» — без этого
диагностика вслепую.

### Чего делать не стоит: Vosk на GPU

Перевести саму Vosk на видеокарту на Windows практически нельзя: официального
GPU-колеса нет, PyPI-пакет заморожен на 0.3.45 (декабрь 2022), а CUDA-сборка
требует самостоятельной сборки Kaldi с `HAVE_CUDA=1` под Linux. К тому же GPU в
Kaldi ускоряет только прямой проход сети (в данном случае это доли секунды) и не
повышает точность. Если нужен именно GPU — это другая нейросеть, например
`faster-whisper`.

## 🔧 Устранение неполадок

| Проблема | Решение |
| --- | --- |
| `run.sh` не запускается в PowerShell | `.sh` — это bash. Используй `run.bat` либо Git Bash. |
| «Модель Vosk не найдена» | Проверь, что внутри `model/` есть подпапка с `conf/`. |
| Нет голоса | Нужен интернет для `edge-tts`; иначе переключись на голос «Системный (SAPI5)» в настройках. |
| Микрофон не слышит | Проверь устройство ввода по умолчанию в Windows; в чат пишется имя подключённого устройства. |
| Клавиатура «залипла» в кото-режиме | Скажи «котик ушел» либо перезапусти ассистента — хук снимется в любом случае. |
| Ошибка установки зависимостей | Обнови pip: `.venv\Scripts\python -m pip install --upgrade pip`, затем `run.bat --reinstall`. |
| Нужны логи | Запусти с флагом `--foreground`. |

## ⚠️ Ограничения

- Только Windows: часть действий (`powercfg`, SAPI5, `rundll32`, блокировка
  клавиатуры) не имеет кроссплатформенных аналогов.
- `run_cmd` и `hotkey` выполняют произвольные команды от имени пользователя —
  редактируй чужие `.command`-файлы с осторожностью.
- Проект не является системным сервисом: окно и трей должны оставаться
  запущенными.
