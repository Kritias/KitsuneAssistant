# Локальный синтез речи, лучший путь (движок Silero TTS v5 на PyTorch + CUDA).
#
# Ставится только в полном режиме при наличии NVIDIA (`full_deps.py`).
# При первом запуске базового режима НЕ качается. Занимает несколько гигабайт
# и тянет CUDA-рантайм; без видеокарты assistant_core выбирает kokoro.
#
# torch берётся из индекса PyTorch, а не с PyPI: на PyPI лежит CPU-сборка,
# и именно из-за неё torch.cuda.is_available() возвращает False даже при
# живой видеокарте. Дополнительный индекс PyPI нужен для зависимостей
# самой сборки (sympy, filelock, jinja2 и прочего), которых нет на
# download.pytorch.org.
#
# Метка cu126 выбрана как база: она поддерживает Ampere (RTX 30xx, sm_86)
# и требует драйвер NVIDIA не старше CUDA 12.6. Если у вас другая карта или
# драйвер, замените cu126 на подходящую метку из списка
#     https://download.pytorch.org/whl/torch/
# (доступны cu118, cu121, cu124, cu126, cu128, cu129, cu130, cu132).
#
# Установка вручную:
#     .venv\Scripts\python.exe -m pip install -r requirements-tts-gpu.txt
#     .venv\Scripts\python.exe tts_local.py silero     # скачать модель
#
# Версии зафиксированы по проверенному рабочему окружению (.venv).

--index-url https://download.pytorch.org/whl/cu126
--extra-index-url https://pypi.org/simple

# Проверенная сборка — 2.14.0+cu126 с индекса PyTorch. Спецификатор без
# локальной метки (==2.14.0) намеренно матчит и +cu126: так зафиксирована
# версия, но выбор CUDA-метки остаётся за --index-url выше.
torch==2.14.0

# Сам код модели Silero v5 внутри .pt использует scipy (ресемплинг и эквалайзер),
# поэтому без него движок не поднимется: torch.package распаковывает модель,
# а её apply_tts упирается в ImportError.
scipy==1.18.1

# Пакет silero в рантайме не используется — модель грузится прямо из .pt через
# torch.package. Оставлен ради CLI и диагностики, стоит копейки рядом с torch.
silero==0.5.5
omegaconf==2.3.1
