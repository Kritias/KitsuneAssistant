# времени), поэтому kokoro — движок по умолчанию там, где нет NVIDIA.
#
# Лаунчеры (run.bat / run.sh) ставят этот файл всегда, но не считают его
# установку критичной: если пакеты не встали, ассистент просто озвучивает
# реплики через edge-tts, а затем через SAPI5.
#
# Установка вручную:
#     .venv\Scripts\python.exe -m pip install -r requirements-tts.txt
#     .venv\Scripts\python.exe tts_local.py kokoro      # скачать модель
